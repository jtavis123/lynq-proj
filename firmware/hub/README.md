# LYNQ Hub

The LYNQ Hub is the central controller, touchscreen interface, automation engine and Alexa-to-Node command router.

## Current target
Waveshare ESP32-S3-Touch-LCD-4.3B-BOX.

## Current release
`v0.2.0-alpha` establishes the ESP-IDF project, boot lifecycle and isolated board port. See `hub/firmware/README.md`.
