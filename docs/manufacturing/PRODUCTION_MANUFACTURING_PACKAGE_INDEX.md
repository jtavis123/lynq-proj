# Production Manufacturing Package Index

Controlled volumes:
1. Product specification and architecture
2. Locked BOM and approved vendor list
3. Mechanical drawings and enclosure machining drawings
4. Assembly work instructions with actual part photographs
5. Electrical and system integration guide
6. Firmware programming, provisioning and recovery
7. Factory acceptance test and burn-in
8. Device History Record and traceability
9. Packaging, labels and customer literature
10. Field installation and service manual
11. Regulatory and certification evidence
12. Design history, risks and engineering changes

## Release gates
The package is not production-releasable until physical measurements, released drawings, production-equivalent testing, firmware artifact hashes, regional compliance review and Quality approval are complete.
