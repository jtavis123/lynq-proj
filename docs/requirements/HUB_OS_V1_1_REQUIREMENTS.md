# Hub OS v1.1 Requirements

1. Boot progress shall be observable and ordered.
2. Required-service failure shall prevent normal Home launch.
3. Cloud loss shall not prevent local UI operation.
4. Board GPIO and display timing shall exist only in the BSP.
5. Settings shall validate brightness, name and timezone before persistence.
6. Diagnostics shall expose firmware, uptime, heap, PSRAM, flash, Wi-Fi, BLE, display, touch, Nodes and alerts.
7. The UI shall target 800x480 landscape with 48-pixel minimum touch targets.
8. Factory Mode shall include display, touch, Wi-Fi, BLE, storage and memory tests.
