# Hub UI Requirements

1. The UI shall target an 800x480 capacitive touchscreen.
2. Primary navigation shall remain accessible from normal top-level pages.
3. Home shall show favorite devices, scenes and active alerts.
4. Connectivity status shall include Wi-Fi, cloud and Alexa.
5. Device pages shall display room, type, Node, availability and safety status.
6. Scene pages shall permit manual execution.
7. Automation pages shall display trigger, enabled state and last run.
8. Learn shall guide the user through capture and replay verification.
9. Settings shall include network, Alexa, Nodes, updates and diagnostics.
10. Destructive or safety-sensitive actions shall require explicit confirmation.
11. UI code shall not block on RF, network, storage or cloud operations.
12. The interface shall remain usable when cloud services are offline.
