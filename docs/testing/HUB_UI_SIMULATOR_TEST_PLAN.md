# Hub UI Simulator Test Plan

## Navigation

- Home, Devices, Scenes, Automations and Settings open correctly.
- Active navigation state follows the selected page.
- No page requires a network connection.

## Devices

- Online device controls change state.
- Offline device controls remain disabled.
- Safety-sensitive devices are visibly identified.
- Device names and rooms remain readable at 800×480.

## Scenes

- Scene cards are easy to distinguish.
- Scene execution updates visible last-run status.
- Scene execution remains separate from safety confirmation logic.

## Automations

- Enabled state can be changed.
- Trigger descriptions are readable.
- Local-execution messaging is visible.

## Status

- Wi-Fi, cloud and Alexa status remain visible.
- Offline Node alerts are prominent without obscuring normal controls.
