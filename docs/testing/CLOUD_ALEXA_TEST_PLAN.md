# Cloud and Alexa Test Plan

- Register a Hub and verify household ownership.
- Hold commands while offline and deliver after reconnection.
- Expire stale commands before delivery.
- Translate supported Alexa directives and reject unsupported ones.
- Route the delivered command through the persistent Device Database and assigned Node.
- Verify accepted, executing, success and failure acknowledgements.
- Record source, device, command and result in activity history.
