# Mechanical Fit and Measurement Record

Measure actual received parts with digital calipers.

Record:

- Hub overall width, height and depth
- Node enclosure external and internal dimensions
- Internal boss locations
- USB-C connector location and insertion clearance
- Module heights with connectors installed
- Grove cable bend radius and service loop
- Lid-to-component clearance
- Antenna keep-out area
- Mounting pad footprint

Do not drill both Node enclosures. Modify and approve one first article, then
transfer the released dimensions to the second enclosure.
