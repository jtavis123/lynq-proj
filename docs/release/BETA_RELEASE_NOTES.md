# LYNQ v2.0.0-beta.1 Release Notes

This integrated beta consolidates the LYNQ Hub OS, Rev A Node OS boundary, RF/IR learning, persistent Device Database, Scenes, Automations, cloud and Alexa boundaries, production Hub UI, physical bring-up procedures and reliability controls.

## Beta goal

Prove one complete physical workflow on the intended Hub and Rev A Node hardware while collecting repeatable reliability evidence.

## Not yet production-ready

- Exact Waveshare BSP must be validated on the physical board revision.
- Exact M5Stack Port ABC GPIO mapping must be validated on received hardware.
- Rev A RF is not universal multi-band RF.
- Cloud services are architectural and simulated, not a hosted production service.
- Alexa is not certified or publicly deployable yet.
- Regulatory, EMC, security and manufacturing certification remain future work.
