# RF/EMC Pre-Compliance Test Plan

Review with an accredited laboratory before testing.

Worst-case modes: Wi-Fi traffic, BLE connection/advertising, RF433 maximum intended duty cycle, IR activity, maximum display load, USB attached, OTA update and simultaneous Hub/Node operation.

Evaluate radiated/conducted emissions, intentional-radiator performance, restricted-band emissions, occupied bandwidth/frequency stability as applicable, RF exposure, immunity/ESD/surge for the target environment, simultaneous transmission, power/cable configuration, labels/manual statements and software controls that prevent unauthorized RF parameters.

Freeze photographs, cable routing, firmware hash and test configuration used for final compliance testing.
