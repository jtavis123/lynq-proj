# Bench Safety and Data Controls

- Remove power before connecting or moving Grove cables.
- Do not machine enclosures with electronics installed.
- Use an ESD-controlled work area.
- Confirm the USB cable supports data.
- Verify flash size before reading or writing flash.
- Never erase the Hub before the factory backup is verified.
- Never flash an artifact with an unverified digest.
- Do not record Wi-Fi passwords, tokens or private keys in logs.
- Keep factory backups and commissioning evidence access-controlled.
- Do not mark a unit accepted solely because a script completed successfully.
