# First Hardware Day — Operator Card

1. Install Bench Console requirements.
2. Photograph the unopened hardware and labels.
3. Disconnect all unrelated ESP devices.
4. Connect only the Waveshare Hub.
5. Run `detect`.
6. Run `chip-info`.
7. Confirm flash capacity.
8. Run `backup-flash`.
9. Copy the backup and JSON sidecar to a second location.
10. Verify the backup SHA-256.
11. Create the commissioning session.
12. Flash only the approved diagnostic image.
13. Capture the complete boot log.
14. Record Hub display, touch, Wi-Fi and BLE results.
15. Disconnect Hub power before moving Node cables.
16. Assemble and test one Node before modifying the second enclosure.
