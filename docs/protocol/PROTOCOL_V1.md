# LYNQ Protocol v1

Initial message classes:

- discovery
- hello
- pair_request
- pair_confirm
- capabilities
- heartbeat
- learn_start
- learn_result
- command_execute
- command_result
- ota_start
- ota_progress
- ota_complete
- error

All messages are versioned. Development builds may use JSON; production transport and encoding remain subject to validation.
