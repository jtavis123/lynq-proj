# LYNQ Hub UI Style Guide

## Theme

- Background: `#0F1115`
- Surface: `#1A1D23`
- Elevated surface: `#252931`
- Primary text: `#F6F7F9`
- Secondary text: `#A4ABB8`
- Accent: `#297EC0`
- Success: `#34C759`
- Warning: `#FF9F0A`
- Danger: `#FF453A`

## Geometry

- Card radius: 18 px
- Small control radius: 12 px
- Base spacing: 8 px
- Minimum touch target: 48x48 px
- Standard horizontal page padding: 24 px

## Typography

- Page title: 30-34 px
- Section title: 20-22 px
- Card title: 18-20 px
- Body: 15-17 px
- Status caption: 13-14 px

## Motion

- Navigation: 180-240 ms
- Card press: subtle scale or surface change
- Avoid decorative motion that delays control
