# LYNQ Project Bible

## Vision

Create the easiest professional platform for bringing existing RF and IR equipment into a modern smart-home or light-commercial automation environment.

## Positioning

LYNQ is not intended to replace Alexa, Home Assistant, or modern smart devices. It bridges legacy remote-controlled equipment into a polished, local-first automation system.

## Product family

- LYNQ Hub
- LYNQ Node One
- LYNQ Node Mini
- LYNQ Node Relay
- LYNQ Node Garage

## Locked product requirements

- Local touchscreen control
- Multi-node architecture
- RF learning and replay
- IR learning and replay
- Alexa voice control through the Hub
- Scenes, schedules, and automations
- Node health monitoring
- Secure pairing
- OTA firmware updates
- No mandatory subscription for core functions

## Current hardware

The first Hub prototype targets the Waveshare ESP32-S3-Touch-LCD-4.3B-BOX. Node One remains an off-the-shelf module-based prototype until the RF/IR design is validated.
