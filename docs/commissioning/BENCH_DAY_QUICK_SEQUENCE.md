# Hardware Arrival Bench-Day Sequence

1. Photograph unopened packages and labels.
2. Verify exact part numbers.
3. Connect only the Hub.
4. Record USB descriptor and COM port.
5. Back up and verify factory flash.
6. Run Hub diagnostics.
7. Measure the Hub and record board revision.
8. Assemble only the first Node.
9. Power the controller/carrier before connecting RF/IR units.
10. Lock the verified Port A/B/C profile.
11. Run Node diagnostics.
12. Pair Hub and Node.
13. Learn and replay one safe command ten times.
14. Disconnect internet and repeat local control.
15. Test backup/restore and OTA rollback.
16. Generate the commissioning report and evidence ZIP.
17. Review defects before modifying the second enclosure.
