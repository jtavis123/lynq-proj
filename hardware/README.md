# Hardware

Authoritative hardware record for LYNQ products.

- `cad/` - mechanical CAD and exports
- `pcb/` - PCB source, fabrication outputs, and board images
- `enclosures/` - enclosure drawings, dimensions, and exploded views
- `wiring-harnesses/` - off-the-shelf harness part numbers and interface drawings
- `schematics/` - electrical schematics
- `test-fixtures/` - production and engineering fixtures
- `images/` - reference photographs
