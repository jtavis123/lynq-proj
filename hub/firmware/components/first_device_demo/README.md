# First Device Demo Integration

This component boundary connects the Hub Learning Wizard, persistent Device Database, command dispatcher, Node transport and Activity History for the first physical demonstration.

Required sequence:

1. Pair one Rev A Node.
2. Capture one IR or supported fixed-code 433 MHz command.
3. Save the learned command and bind it to a device button.
4. Replay the command through the assigned Node.
5. Receive a success or failure acknowledgement.
6. Record the result in Activity History.
